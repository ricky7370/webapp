# 🦄 Leggo con gli Unicorni

Webapp educativa offline per l'allenamento della letto-scrittura, pensata per
bambine e bambini della scuola primaria con **DSA F81.0** (disturbo specifico
della lettura — dislessia).

## ✨ Cosa c'è dentro

Un unico file HTML (`index.html`) con tutta la logica, nessuna dipendenza
esterna, nessuna connessione a server: **i dati restano sul dispositivo**
(`localStorage`).

### 7 giochi mirati

| Gioco | Target DSA |
|-------|------------|
| 🎯 Trova la Doppia | Percezione e scrittura delle consonanti doppie |
| 🔍 Caccia al Digramma | Memorizzazione di digrammi/trigrammi (GN, GL, SC, CH, GH, SCI, GLI, CHI, GHI, CQU, STR, SCR, SPR, SPL) |
| 👀 Occhio alla Lettera | Discriminazione di coppie confuse: p/b, d/b, m/n, f/v, t/d, l/r, c/g, s/z |
| 🕵️ Caccia all'Errore | Ricerca dell'errore ortografico |
| 🧩 Costruisci la Parola | Segmentazione e sintesi sillabica |
| 📚 Parole Magiche | Lettura di parole difficili con sillabe colorate + TTS |
| 🧠 Storie di Unicorni | Comprensione del testo |

### Facilitazioni attivabili per sessione
- 🌈 Sillabe colorate (5 colori in alternanza)
- 🔊 Lettura ad alta voce (TTS italiano, lenta e dolce)
- 💡 Suggerimento scritto
- ✨ Evidenzia difficoltà (doppie in rosa, digrammi in viola)

### Accessibilità DSA
- Font Atkinson Hyperlegible / Verdana ad alta leggibilità
- Dimensione testo: Normale / Grande / Enorme
- Spaziatura lettere: Normale / Larga / Extra larga
- Interlinea: Normale / Alta
- 3 livelli di difficoltà per ogni gioco

### Motivazione
- Collezione di 12 unicorni sbloccabili (0 → 5000 punti)
- Pioggia animata di unicorni ad ogni risposta corretta
- Messaggi di lode e incoraggiamento in rotazione
- Pensiero del giorno motivazionale

### Monitoraggio (per l'adulto)
- Dashboard con sessioni, punti, minuti, accuratezza
- Statistiche per singolo gioco
- Diario errori auto-categorizzato
- Export CSV / backup JSON
- Reset granulare (progressi, errori, unicorni) o totale
